# 這是個人的教學投影片專案

> **給 AI 助理的提示 (For AI Assistants):**
> 請在了解本專案前**優先閱讀此檔案**，這裡包含了本資料夾的核心與架構說明。

本資料夾 (`f:\弘光\課程\114.2`) 是一個**個人的教學投影片與課程資源專案**，屬於弘光科大多遊系 張仕明老師的課程資料。專案以 Markdown 為基礎來撰寫教學簡報，具備自動化建置 (轉存 PDF / 更新網頁) 能力，涵蓋了「程式基礎、遊戲設計、網頁前端、AI 輔助開發」等多門系上核心課程。

## 核心教學內容 (課程分類)
本專案包含了多門課程的教材與投影片，主要分為：

*   **課程須知**
*   **C# 程式設計**：從基礎文法、物件導向到泛型與檔案串流。
*   **手機程式設計**：涉及 2D 遊戲開發、Unity 物理系統、角色控制與手機部署。
*   **互動媒體設計**：分為半學期與一學期，涵蓋 HTML/CSS/JS、Figma UI/UX 設計、RWD 及網站前後端架構。
*   **應用程式設計**：使用 App Inventor 2 開發基礎 App，包含邏輯、畫布繪圖與資料儲存。
*   **Antigravity**：介紹 Agent Skills、Unity MCP 等 AI 開發工具。
*   **獨立投影片**：例如 AI 遊戲開發工作坊等特別企劃。

## 資料夾結構解析
*   **`MD/`**：存放高達上百個 Markdown 格式的投影片原始檔 (通常用 Marp 或類似工具轉換為簡報)。
*   **`PDF/`**：存放由 Markdown 轉換而成、供學生或外部閱覽的 PDF 格式投影片。
*   **`IMAGE/` 與 `MERMAID/`**：存放投影片所需的圖片素材及 Mermaid 流程圖/架構圖。
*   **`display/` & `index.html`**：課程網頁的首頁，用來彙整並展示所有可用課程投影片的連結。
*   **`HoraStyle.css`**：用於自訂投影片或網頁的樣式排版檔。
*   **`.agent/`**：裡面配置有各種自動化小幫手技能 (Skills) 與工作流程 (Workflows)，能幫忙自動匯出投影片、發布更新到 Git、翻譯或進行多媒體素材萃取。
*   **`Blog/`**：部落格文章產生相關目錄。
*   **`NBLM/`, `OLD/`**：舊版資料備份與其他特定用途檔案。

## 自動化與工具腳本
目錄中包含 Python 腳本 (`cleanup_settings.py`, `update_settings_batch.py`)，用於批次處理與維護課程的配置檔或投影片屬性。
