# 本學期課程目標

這是一門**實作導向**的課程。我們將使用 **Unity** 引擎，從零開始打造一款 **2D 橫向捲軸動作遊戲 (Platformer)**。

### 你的期末成果：
1.  一款可以玩的手機遊戲 (APK)。
2.  完整的遊戲製作流程經驗。
3.  了解如何將遊戲發布到手機上。



---

# 學習策略：先做再懂

程式設計很難，但做遊戲很有趣。

### 我們的教學法：
1.  **複製與模仿**：先照著做，讓東西動起來。
2.  **觀察與修改**：試著改改看參數，看看會發生什麼事。
3.  **理解原理**：最後我們再來解釋為什麼要這樣寫。

**不要害怕犯錯，Bug 是寫程式必經的路程！**

---

# 什麼是「手機遊戲」？

手機遊戲 (Mobile Game) 是指運行在智慧型手機或平板電腦上的遊戲。

### 特性：
1.  **隨時隨地**：利用破碎時間遊玩 (通勤、等待時)。
2.  **觸控操作**：沒有滑鼠鍵盤，依靠手指點擊與滑動。
3.  **硬體限制**：手機效能有限，需注意優化與發熱。

---

# iOS 平台詳解

**Apple 的封閉花園**

-   **優點**：
    -   用戶付費意願較高（含金量高）。
    -   硬體規格固定，測試容易，不用擔心奇怪的解析度。
    -   系統更新率高，新功能推廣快。
-   **缺點**：
    -   必須要有 Mac 電腦才能打包發布。
    -   上架審核非常嚴格，重視隱私與品質。

---

# Android 平台詳解

**Google 的綠色機器人**

-   **優點**：
    -   市佔率全球第一，用戶基數大。
    -   上架門檻低，費用便宜。
    -   開發彈性大，可以直接傳 APK 給朋友安裝。
-   **缺點**：
    -   **碎片化嚴重**：螢幕尺寸、解析度、效能千奇百怪。
    -   盜版問題較嚴重。

---

# 軟體商店比較

| 項目 | Apple App Store | Google Play Store |
| :--- | :--- | :--- |
| **審核時間** | 1~3 天 (人工) | 數小時~1 天 (機器+人工) |
| **退件率** | 高 | 低 |
| **抽成比例** | 30% (小型開發者 15%) | 30% (小型開發者 15%) |
| **主要市場** | 美國、日本、歐洲 | 亞洲、南美、新興市場 |

# 開發方式：原生 vs 跨平台

要怎麼寫出同時能在 iOS 和 Android 跑的遊戲？

### 1. 原生開發 (Native)
-   寫兩次：用 Swift 寫 iOS，用 Kotlin 寫 Android。
-   優點：效能最好。
-   缺點：**累！成本高！**

### 2. 跨平台開發 (Cross-Platform) 👑
-   寫一次：用 Unity 或 Unreal。
-   優點：**省時省力**，寫完按個按鈕就能輸出雙平台。
-   缺點：檔案通常比較大一點點。

---

# 什麼是「遊戲引擎」？

如果沒有引擎，要讓一張圖片在螢幕上動起來，你需要：

1.  寫 C++ 跟顯示卡驅動程式溝通 (OpenGL/DirectX/Vulkan)。
2.  自己寫數學公式算物理 (重力加速度、碰撞反彈)。
3.  自己寫程式解碼 MP3 音效。
4.  自己寫程式讀取圖片格式 (PNG/JPG)。

**這太痛苦了！我們是來做遊戲，不是來發明輪子的。**

---

# 引擎幫我們做了什麼？

遊戲引擎 (Game Engine) 是一個整合開發環境，提供了：

-   **渲染引擎 (Rendering)**：負責畫圖、光影。
-   **物理引擎 (Physics)**：負責模擬真實世界的物理反應。
-   **音效系統 (Audio)**：負責播放音樂與音效。
-   **輸入系統 (Input)**：負責偵測觸控、搖桿、鍵盤。
-   **腳本系統 (Scripting)**：讓你寫邏輯控制遊戲。

---

# 常見遊戲引擎：Unity

-   **市佔率王者**：全球超過 50% 手遊使用 Unity 開發。
-   **特點**：
    -   介面親民，適合初學者。
    -   跨平台能力強大 (支援 20+ 平台)。
    -   使用 **C#** 語言。
-   **代表作**：《傳說對決》、《原神》、《Among Us》、《Pokémon GO》。

---

# 常見遊戲引擎：Unreal Engine

-   **畫質怪獸**：以超高品質的 3D 畫面著稱。
-   **特點**：
    -   適合 3A 級大作與 PC/Console 遊戲。
    -   藍圖系統 (Blueprint) 讓不寫程式也能開發。
    -   使用 **C++** 或藍圖。
-   **代表作**：《Fortnite》、《黑神話：悟空》、《FF7 重製版》。

---

# 常見遊戲引擎：Godot & 其他

-   **Godot**：
    -   開源免費，近年來異軍突起。
    -   極度輕量化 (幾百 MB)。
    -   適合 2D 獨立遊戲。
-   **Cocos Creator**：
    -   在 2D 手遊與小遊戲領域也有一席之地。

---

# 為什麼我們選擇 Unity？

1.  **就業需求**：台灣遊戲業徵才需求最高的引擎。
2.  **學習資源**：網路上教學多到看不完，遇到問題容易找答案。
3.  **Asset Store**：強大的素材商店，缺模型、缺音效、缺程式，買就對了 (或找免費的)。
4.  **免費使用**：對學生與年收 10 萬美元以下的個人開發者完全免費。

---

# Unity 版本命名規則

你會看到 Unity 有很多版本，例如 `2022.3.10f1`。

-   **2022**：主要年份版本。
-   **3**：次要更新。
-   **10f1**：小修正版本。

### 什麼是 LTS？
**LTS = Long Term Support (長期支援版)**
-   最穩定，官方承諾維護 2 年。
-   **做專案強烈建議使用 LTS 版本**，避免用到不穩定版導致專案壞掉。
-   本學期建議使用：**Unity 2022.3 LTS**。

# 環境建置：Unity Hub

我們不會直接下載 "Unity"，而是先下載 **Unity Hub**。

### Unity Hub 的功能：
1.  **專案管理**：列出你所有的專案路徑。
2.  **版本管理**：讓電腦同時安裝好幾個不同版本的 Unity Editor。
3.  **帳號管理**：登入 Unity ID，管理授權。
4.  **社群學習**：瀏覽官方教學與範例。

---

# 安裝步驟 1：下載 Unity Hub

請前往 Unity 官網下載：
[unity.com/download](https://unity.com/download)

1.  點選 **Download Unity Hub**。
2.  安裝並執行。
3.  你需要註冊一個 **Unity ID** (免費) 並登入。
    -   建議使用 Google 帳號快速註冊。
    -   這會用來取得個人的免費授權 (Personal License)。

---

# 安裝步驟 2：啟用授權

1.  開啟 Unity Hub 左上角的齒輪圖示 (Preferences)。
2.  選擇 **Licenses**。
3.  點選 **Add** -> **Get a free personal license**。
4.  同意條款後，你就有合法的免費使用權了！

*(如果沒有授權，你將無法使用 Unity Editor)*

---

# 安裝步驟 3：安裝 Editor

1.  回到 Hub 主畫面，點選左側 **Installs**。
2.  點選右上角 **Install Editor**。
3.  切換到 **Official Releases** 或 **Recommended Version**。
4.  找到 **2022.3.x (LTS)** 版本，點選 **Install**。

---

# 安裝步驟 4：選擇模組 (Modules)

這步最重要！一定要勾選對的模組。

請勾選：
-   **Android Build Support** (包含 OpenJDK 與 SDK/NDK Tools)。
-   *(選用) iOS Build Support* (除非你有 Mac 且想出 iOS)。
-   *(選用) Mac Build Support* (如果你用 Mac)。
-   *(必要) Microsoft Visual Studio Community 2022* (如果你電腦沒裝過 VS)。
    -   這是用來寫程式碼的工具。

---

# 程式編輯器：Visual Studio

Unity 本身只能「設定」遊戲，要「寫邏輯」需要外部的 IDE。

-   **Windows 推薦**：**Visual Studio Community 2022**
    -   功能最強，除錯最方便，Unity 安裝時會自動以此為預設。
-   **輕量選擇**：**Visual Studio Code (VS Code)**
    -   開啟速度快，但需要自己安裝 C# Dev Kit 外掛，設定較繁瑣。

*(本課程示範將使用 Visual Studio 2022)*

---

# 建立第一個專案

1.  回到 Hub 主畫面，點選左側 **Projects**。
2.  點選右上角 **New project**。
3.  在上方的選單選擇剛裝好的 Editor 版本 (2022.3 LTS)。
4.  選擇模板 (Template)：**2D Core (URP)** 或 **2D Core**。
    -   我們做 2D 遊戲，選 2D 模板會幫我們預設好相機與圖片設定。

---

# 專案命名與路徑

⚠️ **極度重要！新手常犯錯誤** ⚠️

1.  **路徑不要有中文**：
    -   ❌ `C:\使用者\小明\我的遊戲`
    -   ⭕ `D:\UnityProjects\MyFirstGame`
    -   中文路徑極容易導致編譯錯誤或建置失敗。
2.  **專案名稱不要有空格**：
    -   建議使用駝峰式 (MyGame) 或底線 (My_Game)。

---

# Unity 介面初體驗

當你第一次打開 Unity，你會看到五大視窗，別被嚇到了：

1.  **Scene (場景)**：編輯區，你是上帝，在這裡擺放物件。
2.  **Game (遊戲)**：預覽區，玩家看到的畫面。
3.  **Hierarchy (階層)**：清單區，列出場景裡所有東西的名稱。
4.  **Project (專案)**：倉庫區，存放所有檔案 (圖片、聲音、腳本)。
5.  **Inspector (屬性)**：設定區，修改選中物件的詳細數值 (位置、顏色)。
