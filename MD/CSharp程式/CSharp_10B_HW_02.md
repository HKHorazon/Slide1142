# 作業題目 1：5 的倍數總和 (Ch.7 - 迴圈)

### 題目說明
請撰寫一個程式，使用 `for` 或 `while` 迴圈，計算指定範圍內所有 **5 的倍數** 的總和。

### 輸出說明
- 印出 1 到 100 之間所有 5 的倍數加總結果。
- 範例輸出：1050

# 作業題目 2：計算平均分數 (Ch.8 - 陣列)

### 題目說明
請宣告一個包含以下成績的整數陣列，並計算其平均分數：
`{ 75, 60, 42, 90, 85 }`

### 輸出說明
- 印出這 5 個成績的 **平均分數** (整數或浮點數皆可)。
- 範例輸出：70.4

# 作業題目 3：尋找及格者 (Ch.8 - 陣列與判斷)

### 題目說明
延續上題的成績陣列 `{ 75, 60, 42, 90, 85 }`，請找出所有 **及格 (>= 60)** 的分數。

### 輸入說明
- 使用程式內建的陣列資料。

### 輸出說明
- 使用 `foreach` 迴圈列出所有及格的分數。
- 在分數後方加上 `(及格)` 字樣。 範例輸出：
```
  75 (及格)
  60 (及格)
  90 (及格)
  85 (及格)
```

# 作業題目 4：自訂函式應用 (Ch.10 - 函式)

### 題目說明
請撰寫一個程式，練習定義與呼叫兩個不同的「自訂函式（Method）」，用來計算並輸出長方形的面積。

### 輸入與輸出範例
- 輸入：
  ```csharp
   8
   5
  ```
- 輸出： 
  ```csharp
  長方形的面積是：40
  ```

--- 
#  作業題目 4：自訂函式應用 (Ch.10 - 函式)

### 實作步驟
1. **定義第一個函式**（負責計算）：例如寫一個 `CalculateArea(int width, int height)`，用來計算面積並**回傳**結果（`return width * height;`）。
2. **定義第二個函式**（負責輸出）：例如寫一個 `PrintResult(int area)`，不需回傳值（`void`），只負責將傳入的面積印到螢幕上。
3. **在 `Main` 程式中呼叫** (或說，"最上層"無函式區域)：
   - 設定一組長寬數字（例如寬度 5、高度 8）。
   - 先呼叫第一個函式算出面積，把結果存起來。
   - 再將算出的結果丟給第二個函式印出來。
