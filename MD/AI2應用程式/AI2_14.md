# 靜態與動態

之前的元件 (Button, Label) 都是「卡」在 Layout 裡的，不能隨便亂跑。
如果我們要做遊戲 (Game) 或 動畫 (Animation)，物件需要：

1. **自由移動** (改變 X, Y)。
2. **互相重疊**。
3. **發生碰撞**。

這時候就需要 **畫布 (Canvas)**。

---

# 1. 畫布 (Canvas)

在 **Drawing and Animation** 抽屜裡。

- **Canvas 是一個容器**：所有的動畫元件 (Sprite, Ball) 只能放在 Canvas 裡面。
- **座標系統 (Coordinate System)**：
  - **(0, 0)** 原點在 **左上角**。
  - **X 軸**：往右增加 (Width)。
  - **Y 軸**：往下增加 (Height)。

> **設定建議**：通常把 Canvas 的 Width 和 Height 都設為 **Fill Parent**，佔滿整個空間。

---

# 2. 精靈 (Sprite) 的種類

### Ball (球)
- 內建的圓形，不用找圖。
- 屬性：`Radius` (半徑), `Color` (顏色)。

### ImageSprite (圖片精靈)
- 可以設定圖片 (Picture)。
- 這是做遊戲最常用的角色元件 (瑪利歐、飛機、怪獸)。

---

# 精靈的運動屬性

怎麼讓它動起來？

- **X / Y**: 目前位置。
- **Heading (方向)**: 0~360 度。
  - 0 (右), 90 (上), 180 (左), 270 (下) *(注意：AI2 的角度定義可能跟數學略有不同，要測試一下)*
- **Interval (更新間隔)**: 毫秒。
- **Speed (速度)**: 每次更新移動多少像素。

> 只要設定 Speed > 0，它就會自動往 Heading 的方向跑！

---

# 互動事件：被摸到了 (Touched)

這就是「點擊」事件，但比 Button 更強。

`當 ImageSprite.Touched (x, y)`

- `x, y`: 告訴你點在精靈的哪個位置 (適合做精準射擊)。
- **應用**：打地鼠。
  - 當地鼠被摸到 -> 分數 + 1，地鼠換位置。

---

# 互動事件：被滑動 (Dragged)

手指按著螢幕不放並在上面滑動。

`當 Canvas.Dragged (startX, startY, prevX, prevY, currentX, currentY)`

- **prevX/Y**: 上一個點。
- **currentX/Y**: 現在的點。

### 應用：小畫家
```blocks
呼叫 Canvas.DrawLine
    x1: prevX, y1: prevY
    x2: currentX, y2: currentY
```
把滑過的軌跡連成線，就是在畫畫了！

---

# 互動事件：被甩動 (Flung)

手指快速滑過 (像切水果、丟寶貝球)。

`當 ImageSprite.Flung (x, y, speed, heading)`

- **speed**: 甩多快。
- **heading**: 甩的方向。

### 應用：投籃遊戲
當球被 Flung -> 設定球的 Speed 和 Heading 等於手甩的數值 -> 球就會飛出去！

---

# 物理反應：碰到邊緣與彈跳

當球跑到畫面外面會怎樣？它會繼續跑，直到消失在宇宙盡頭。
如果想把它關在畫面裡？

`當 Ball.EdgeReached (edge)`
- `edge`: 代表碰到哪一邊 (常數代號)。

`呼叫 Ball.Bounce (edge)`
- 讓球自動反彈！(就像撞球一樣)

---

# 碰撞偵測 (Collision Detection)

當兩個精靈撞在一起時...

`當 ImageSprite.CollidedWith (other)`
- `other`: 撞到誰了？

### 應用：吃金幣
```blocks
如果 (other == 金幣)
    金幣.Visible = False (吃掉)
    分數 + 1
如果在 (other == 敵人)
    Game Over
```

---

# 實作挑戰：專注力訓練 (碰碰球)

1. 畫面放一個 Ball (玩家)，用 Dragged 控制它跟著手指動。
2. 畫面放三個 Ball (敵人)，設定 Speed 讓它們亂跑，並且碰到邊緣會 Bounce。
3. **規則**：
   - 玩家要閃避敵人。
   - 如果 `CollidedWith` 敵人 -> 遊戲結束。
   - 堅持越久分數越高 (用 Timer 計時)。

---

# 重點回顧

1. **Canvas**: 動畫的世界與座標系。
2. **Sprite**: 會動的角色 (Ball / ImageSprite)。
3. **Movement**: 利用 Speed 和 Heading 自動移動。
4. **Interaction**: Touched, Dragged, Flung。
5. **Physics**: EdgeReached (反彈) 與 CollidedWith (碰撞)。
