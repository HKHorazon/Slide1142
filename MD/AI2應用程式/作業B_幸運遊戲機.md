# 作業說明

製作經典的益智遊戲 **「幾A幾B (Bulls and Cows)」**！
這是一個考驗邏輯與程式技巧的經典題目。

### 遊戲規則
1. 系統產生一組 **4 位數** 的謎底 (數字 0~9，**不重複**)。
2. 玩家輸入 4 個數字猜猜看。
3. 系統判斷：
   - **A (位置對，數字對)**：數字和位置都正確。
   - **B (位置錯，數字對)**：數字正確，但位置不對。
4. 例如：答案 `1234`，猜 `1543` → **1A2B** (1 位置對，3和4有這數字但位置錯)。
5. 目標：猜出 **4A0B** (完全正確)！

---

# 核心功能與資料結構

### 1. 產生謎底 (List)
我們需要一個 **清單 (List)** 來存謎底，例如 `[1, 5, 2, 8]`。
- 使用 `While` 迴圈 + `Random` 亂數 + `is in list` 檢查，產生 4 個不重複的數字。

### 2. 玩家輸入
- 用 **TextBox** 讓玩家輸入 (記得限制長度為 4，且 NumbersOnly)。
- 或者設計 0~9 的數字按鈕讓玩家點選。

### 3. 判斷邏輯 (演算法)
這需要用到 **雙重迴圈** 或者 **包含檢查**：
- 檢查 A：第 `i` 個字是否等於謎底的第 `i` 個字？
- 檢查 B：如果不是 A，那這個字有沒有在謎底清單中？

# 畫面設計參考

### 必備元件
- **Button**：「開始新遊戲」 (產生新謎底)
- **TextBox**：輸入猜測數字

  - 例如：「第1次: 1234 -> 1A2B」
  - 這樣玩家才不用拿紙筆記！

# 程式邏輯：判斷 A 和 B

這段是最難的，這邊提供邏輯思維 (虛擬碼)：

```blocks
設變數 A = 0
設變數 B = 0

// 假設謎底是 AnswerList，玩家猜的是 GuessList (兩個都是清單)
For each number i from 1 to 4
    如果 (GuessList[i] == AnswerList[i])
        A = A + 1
    否則如果 (AnswerList 包含 GuessList[i])
        B = B + 1

顯示：A + "A" + B + "B"
```

*小撇步：如果玩家輸入的是文字字串 (Text)，可以用 Text 分割功能把它變成清單，或者直接用文字處理積木來比對。*

# 加分挑戰

### 1. 只有 4 個數字不夠玩？
- 讓玩家選擇難度：3位數、4位數、5位數。

### 2. 防呆機制 (Validator)
- 如果玩家輸入重複數字 (例如 1122) 怎麼辦？
- 如果玩家輸入不足 4 位數怎麼辦？
- 顯示警告：**Notifier.ShowAlert** ("請輸入4個不重複數字！")

### 3. 限時挑戰
- 加入 **Clock** 計時器。
- 限制 60 秒內要猜出來，不然就爆炸(Game Over)！
