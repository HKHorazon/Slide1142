# 本章目標

1. 學習 **TextToSpeech (文字轉語音)**。
2. 學習 **SpeechRecognizer (語音辨識)**。
3. 區分 **Sound** 與 **Player** 的差異。
4. 實作：多國語言翻譯發音 App。

---

# 為什麼需要多媒體？

App 如果只有文字和圖片，互動感很弱。
加上**聲音 (Audio)** 和 **語音 (Voice)**，可以：

- 幫助視障人士 (無障礙)。
- 增加遊戲沉浸感。
- 做出口語練習 App。
- 做出聲控助理。

---

# 1. 讓 App 說話 (TextToSpeech)

在 **Media** 抽屜裡，拉 `TextToSpeech` 元件進來 (它是隱藏元件)。

### 程式積木
`呼叫 TextToSpeech1.Speak (message)`

例如：
```blocks
當 按鈕.被點選
    呼叫 TextToSpeech1.Speak ("歡迎光臨！")
```
它就會用系統內建的語音引擎 (TTS Engine) 唸出來！

---

# TTS 進階設定

TextToSpeech 還有一些屬性可以玩：

- **Pitch (音調)**: 聲音高低。
  - 1.0 (正常), 2.0 (花栗鼠), 0.5 (低沉男聲)。
- **SpeechRate (語速)**: 講話快慢。
  - 1.0 (正常), 2.0 (快嘴), 0.5 (樹懶)。
- **Language / Country**: 設定語言。
  - 預設通常會跟隨手機系統語言。

---

# 2. 聽懂你說話 (SpeechRecognizer)

也是在 **Media** 抽屜。這就是 Siri 或 Google Assistant 的核心功能。

### 使用步驟
1. 呼叫 `GetText`：啟動麥克風，畫面會出現 Google 的語音視窗。
2. 等待 `AfterGettingText (result)`：當使用者講完話，這個事件會被觸發。
   - `result` 參數就是轉換出來的文字。

---

# 實作：聲控開關

我們來做一個「聲控燈」。

```blocks
當 語音按鈕.Click
    呼叫 SpeechRecognizer.GetText

當 SpeechRecognizer.AfterGettingText (result)
    如果 (result 包含 "開燈")
        設 Screen1.BackgroundColor 為 黃色
    否則如果 (result 包含 "關燈")
        設 Screen1.BackgroundColor 為 黑色
    否則
        呼叫 TextToSpeech.Speak ("我聽不懂：" & result)
```

> **contains text** 積木在 Text 抽屜，用來檢查關鍵字。

---

# 3. 播放聲音 (Sound vs Player)

AI2 有兩個播放聲音的元件，請不要搞混：

### A. Sound (音效)
- **特色**：載入快，適合**短音效**。
- **限制**：不能暫停，只有播放。
- **用途**：按鈕聲、得分聲、爆炸聲、叮咚聲。
- **特殊功能**：`Vibrate (震動)` 積木在這裡！

### B. Player (播放器)
- **特色**：功能完整，適合**長音樂**。
- **功能**：Start, Pause, Stop, Volume, Loop (循環)。
- **用途**：背景音樂 (BGM)、播放整首歌曲。

# 練習：動物叫聲 App

準備三張圖片：狗、貓、牛。
準備三個音檔：dog.mp3, cat.mp3, cow.mp3。

1. 上傳音檔到 Media。
2. 拉三個 Sound 元件 (Sound1, Sound2, Sound3)，Source 分別設好。
3. 當 圖片狗.Click -> `Sound1.Play`。
4. 當 圖片貓.Click -> `Sound2.Play`。

> 這是幼稚園等級的 App，但很有趣！

# 實作挑戰：Google 翻譯發音員

結合 **YandexTranslate** (在 Media 裡) 和 **TextToSpeech**。

1. **輸入框**：輸入中文。
2. **翻譯按鈕**：
   - 呼叫 `YandexTranslate.RequestTranslation`
   - 來源: zh, 目標: en
3. **當 GotTranslation (result)**：
   - 顯示翻譯結果。
   - 呼叫 `TextToSpeech.Speak (result)` (記得語言要切成英文)。

> 註：Yandex 有時候需要 API Key，如果不能用，可以改做單純的「輸入什麼唸什麼」發音機。

---

# 應用：整人玩具

利用 Timer + Sound。

1. **Clock 元件**：設 TimerEnabled = False。
2. **設定按鈕**：按下後，啟動 Timer (倒數 10 秒)。
3. **當 Timer 到了**：
   - 播放尖叫聲 (Sound.Play)。
   - 手機震動 (Sound.Vibrate 2000 ms)。

*請勿對心臟病患使用。*

---

# 重點回顧

1. **TTS**: 讓機器有嘴巴。
2. **Speech Recog**: 讓機器有耳朵。
3. **Sound**: 短音效 + 震動。
4. **Player**: 長音樂 + 控制 (暫停/重播)。
