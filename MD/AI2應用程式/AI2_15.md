# 手機感測器 (Sensors)

手機與電腦最大的不同，就是它有很多「感覺器官」。

- **加速度感測器 (Accelerometer)**: 偵測晃動、傾斜。
- **陀螺儀 (Gyroscope)**: 偵測旋轉 (VR/AR)。
- **定位感測器 (Location)**: GPS 經緯度。
- **方向感測器 (Orientation)**: 指北針。
- **光線感測器 (Light)**: 環境亮度。

---

# 實作：搖搖樂 (Accelerometer)

加速度感測器可以偵測手機在 X, Y, Z 三軸的移動。
最簡單的應用就是 **Shaking (搖晃)** 事件。

### 搖一搖換桌布
1. 拉一個 AccelerometerSensor (隱藏元件)。
2. 程式邏輯：

```blocks
當 AccelerometerSensor1.Shaking
    設 Image1.Picture 為 (隨機選一張圖)
    呼叫 Sound1.Vibrate (500)
```

> 這是很多抽籤、骰子 App 的基礎玩法。

---

# 實作：水平儀 (Level)

利用 `XAccel` (左右傾斜) 和 `YAccel` (前後傾斜) 的數值。

- **數值範圍**：大約在 -10 ~ 10 之間 (重力加速度 9.8)。
- **應用**：
  - 控制球的滾動 (像彈珠台)。
  - 檢查桌子有沒有平。

> 技巧：把 Canvas 裡的 Ball 的 Speed 設為 XAccel 的絕對值，Heading 設為傾斜方向，就可以做體感遊戲了！

# 連接世界 (Connectivity)

在 Connectivity 抽屜裡：

### 1. ActivityStarter (活動啟動器)
呼叫手機裡的其他 App。
- **開啟瀏覽器**: Action = `android.intent.action.VIEW`, DataUri = `http://google.com`
- **撥打電話**: Action = `android.intent.action.DIAL`, DataUri = `tel:123456`
- **開啟 Google Maps**: DataUri = `geo:24.123,120.456`

### 2. Web (網路)
呼叫網路 API (Application Programming Interface)。
- 抓取天氣資料 (JSON)。
- 抓取股票資訊。

# 實作：簡單瀏覽器

我們可以用 **WebViewer** (在 UserInterface 抽屜) 來做一個自己的瀏覽器。

1. **介面**:
   - TextBox (輸入網址)
   - Button (前往)
   - WebViewer (佔滿下方)

2. **程式**:
   - 當 Button.Click -> `呼叫 WebViewer1.GoToUrl (TextBox.Text)`。

簡單吧！但要注意網址要有 `http://` 或 `https://`。

# 資料儲存 (Storage)

### 1. TinyDB (微型資料庫)
- **存在手機裡** (Local Storage)。
- Key-Value 結構 (標籤-值)。
- **用途**：最高分紀錄、使用者設定 (音量、名稱)。
- **缺點**：換手機資料就不見了。

### 2. CloudDB / Firebase
- **存在雲端** (Cloud Storage)。
- **用途**：即時聊天室、多人連線遊戲、線上排行榜。
- **缺點**：需要網路，設定較複雜。

# 實作：記住我的名字

做一個「設定頁面」，存入名字後，下次打開 App 還是記得。

1. **存檔**:
   `呼叫 TinyDB1.StoreValue tag "username" valueToStore (輸入框.文字)`

2. **讀檔 (初始化時)**:
   `設 輸入框.文字 為 (呼叫 TinyDB1.GetValue tag "username" valueIfTagNotThere "")`

> `valueIfTagNotThere`: 如果找不到 (例如第一次開)，要回傳什麼預設值？通常給空字串。

# 什麼是 Extensions (擴充元件)？

App Inventor 原生的積木有限 (雖然已經很多了)。
但是全球的開發者社群開發了很多 **.aix** 檔案，可以匯入使用！

### 常見擴充
- **TaifunSystem**: 開手電筒、調整螢幕亮度、取得手機電量。
- **Phase**: 漂亮的動畫轉場效果。
- **DeepHost**: 圓角圖片、特殊的 Listview。
- **BluetoothLE**: 低功耗藍牙 (連 Arduino/ESP32)。

### 如何使用
1. 下載 .aix 檔案。
2. 在 Palette 最下方點 "Extension" -> "Import extension"。
3. 就像普通元件一樣拉進來用！

---

# 重點回顧

1. **Sensors**: 讓 App 有「感覺」，做出體感互動。
2. **ActivityStarter**: 呼叫外部 App，不要什麼都自己寫。
3. **TinyDB**: 讓資料持久化，不會關掉就沒了。
4. **Extensions**: 當內建功能不夠用時，去社群找擴充！
