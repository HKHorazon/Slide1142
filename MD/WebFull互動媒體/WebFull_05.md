# 為什麼工程師要學設計？

<br>

寫程式很重要，但**設計**是產品與使用者溝通的橋樑。

-   **溝通效率**：懂設計術語，跟設計師溝通無障礙。
-   **獨立開發**：接案或做 Side Project 時，能自己做出不難看的介面。
-   **使用者體驗**：寫出的程式不只「能用」，還要「好用」。

> **「好看的東西，大家會覺得它比較好用。」** (美觀實用性效應)

---

# UI vs UX：有什麼差別？

<br>

這兩個詞常被連在一起講，但意義完全不同。

### UI (User Interface) - 使用者介面
-   **視覺層面**：長得好不好看？
-   **元素**：按鈕顏色、字體大小、排版間距、圖示風格。
-   **產出**：高保真視覺稿 (Mockup)。

### UX (User Experience) - 使用者體驗
-   **感受層面**：好不好用？順不順暢？
-   **流程**：註冊要在三步內完成、按鈕位置是否好按。
-   **產出**：Wireframe、流程圖 (User Flow)、使用者研究。

---

# UI/UX 的譬喻

<br>

想像一下 **蕃茄醬瓶**。

-   **UI (介面)**：
    -   玻璃瓶身，貼著漂亮的紅標籤，看起來很有質感。
    -   (即使很難倒出來，但它放在桌上很好看)

-   **UX (體驗)**：
    -   改用軟塑膠瓶，瓶口倒置設計。
    -   (雖然沒那麼高級，但隨便擠就出來，還不會弄髒手)

> **好的設計通常兼具 UI 與 UX。**

---

# 介面設計四原則 (CRAP)

<br>

只要掌握這四點，你的設計就不會太醜。

1.  **對比 (Contrast)**：
    -   即使是白底黑字，也要夠黑。標題要夠大，讓重點跳出來。
2.  **重複 (Repetition)**：
    -   同樣的按鈕就要長一樣，標題字體要統一。建立一致性。
3.  **對齊 (Alignment)**：
    -   不要隨便擺放，所有東西都要有對齊線。置中或靠左，選一個。
4.  **親密性 (Proximity)**：
    -   相關的東西靠還有近一點，不相關的分開遠一點。

# 認識 Figma

<br>

## [Figma](https://www.figma.com/) - UI 設計工具。


### 為什麼是 Figma？
-   **雲端協作**：不用存檔寄給別人，給連結就好，像 Google Docs。
-   **跨平台**：瀏覽器就能跑，Mac/Windows 通吃。
-   **社群強大**：有成千上萬個免費的 Plugins 和 UI Kits。
-   **免費**：對學生跟個人使用者超級佛心。

---

# 第一步：註冊與開啟

<br>

1.  **註冊帳號**：
    -   前往 [Figma.com](https://www.figma.com/) 點擊 "Get started"。
    -   建議使用 Google 帳號直接登入。

2.  **建立畫布**：
    -   點擊右上角的 **"Design file"** (藍色按鈕)。
    -   選擇 **"New design file"**。
    -   現在，你擁有了一個專屬的設計空間！

---

# Figma 介面導覽

<br>

打開 Figma，你會看到三個主要區塊：

1.  **中間：畫布 (Canvas)**
    -   無限大的空間，讓你自由揮灑。
2.  **左側：圖層 (Layers) 與 素材 (Assets)**
    -   管理你的 Frame、群組、元件。
3.  **右側：屬性面板 (Properties)**
    -   調整顏色、大小、字體、對齊、匯出設定。
4.  **上方：工具列 (Toolbar)**
    -   選取、形狀、畫筆、文字、移動手手。

---

# 第一步：建立畫框 (Frame)

<br>

在 Figma 裡，我們不叫「畫布」或「頁面」，我們叫 **Frame** (快速鍵 `F`)。

-   按下 `F`，右邊會出現各種尺寸預設值。
-   **Phone**: iPhone 14, Android Large...
-   **Desktop**: MacBook Pro, Desktop...
-   **Social Media**: Instagram Post, Twitter Header...

> **Frame 不只是畫框，它也是一個容器 (Container)。**

---

# 基本形狀與操作

<br>

-   **矩形 (R)**：做按鈕、卡片背景。
-   **圓形 (O)**：做頭像、裝飾圓點。
    -   *按住 Shift 拉動 = 正圓/正方形*。
-   **文字 (T)**：輸入內容。
-   **移動 (V)**：選取與移動物件。
-   **縮放 (K)**：**重要！** 用 V 拉會改變長寬但不改變筆畫粗細，用 K (Scale) 才會等比例縮放所有屬性。

---

# 顏色與填充

<br>

選取物件後，看右邊屬性面板：

-   **Fill (填充)**：物件內部的顏色。
    -   支援 Solid (純色), Linear (漸層), Image (圖片)。
-   **Stroke (邊框)**：物件外圍的線條。
    -   可以設定粗細、顏色、虛線。
-   **Effects (特效)**：
    -   **Drop Shadow** (陰影)：增加立體感。
    -   **Layer Blur** (模糊)：做毛玻璃效果。

---

# 圖片處理

<br>

在 Figma 放圖片超簡單：
1.  直接把圖片檔拖進去。
2.  或是畫一個形狀，Fill 選擇 Image。

### 遮罩 (Mask)
想做「圓形頭像」？
1.  放一張照片。
2.  畫一個圓形，放在照片**下面**。
3.  同時選取兩者，按下上方工具列的 **Use as mask** (月亮圖示)。

---

# 排版神器：Auto Layout (Shift + A)

<br>

這是 Figma 最強大的功能，必學！
它就像 CSS 的 `Flexbox`。

-   選取多個物件，按 `Shift + A`。
-   它們會變成一個具有彈性的容器。
-   **好處**：
    -   或是拖拉調換順序，其他物件會自動補位。
    -   內容變多，容器會自動長高。
    -   調整間距 (Gap) 只要改一個數字，不用一個一個移。

---

# 元件 (Component, Ctrl/Cmd + Alt + K)

<br>

做 UI 一定會有重複的東西 (例如：按鈕、導覽列)。

-   把做好的按鈕變成 **Master Component** (紫色菱形)。
-   複製出來的叫 **Instance** (空心菱形)。
-   **修改 Master，所有的 Instance 都會跟著變！**
-   省去「一個一個改顏色」的痛苦時間。

---

# 實作練習：登入畫面

<br>

我們來練習做一個簡單的手機版登入頁面。

1.  **Frame**：選 iPhone 14。
2.  **背景**：填入一個深色背景 (`#1E1E1E`)。
3.  **Logo**：打上文字 APP NAME，字體加大加粗。
4.  **輸入框**：
    -   畫一個矩形，圓角設 8。
    -   加上灰色邊框，裡面打「請輸入帳號」。
    -   複製一份做密碼框。
5.  **按鈕**：
    -   畫一個矩形，填入主色 (`#EA580C`)。
    -   上面打「登入」，文字置中。
    -   將矩形與文字群組起來 (Ctrl+G)。

---

# 插件推薦 (Plugins)

<br>

Figma 的外掛讓它如虎添翼：

1.  **Unsplash**：直接在 Figma 裡搜尋並插入無版權高品質圖片。
2.  **Iconify**：幾萬個 Icons 隨你用，不用去網站下載 SVG。
3.  **Lorem Ipsum**：自動產生假文，填版面用。
4.  **Remove BG**：一鍵去背 (需 API Key)。
5.  **Blobs**：生成不規則的有機形狀，做背景裝飾很好用。

---

# 輸出 (Export)

<br>

設計做好了，要怎麼給工程師 (或是你自己)？

1.  選取你要輸出的 Frame 或物件。
2.  右下角 **Export** 區塊。
3.  選擇格式：
    -   **PNG/JPG**：一般圖片。
    -   **SVG**：向量圖 (Icon 必選)。
    -   **PDF**：文件。
4.  點擊 Export 按鈕。

> **Dev Mode** (開發者模式)：現在 Figma 對免費用戶有限制，但我們還是可以看到基本的 CSS 代碼 (Inspect 面板)。
