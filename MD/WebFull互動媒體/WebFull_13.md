# 前端開發的演進

<br>

以前我們寫網頁，都是 HTML、CSS、JavaScript 分開寫（也就是所謂的「前端三劍客」）。

但隨著網頁功能越來越複雜（像是 Facebook、Gmail，已經不能算是「網頁」，而是「應用程式」），傳統的寫法變得難以維護。

因此，**現代網頁製作** 誕生了許多新的技術與框架，幫助我們建立大型、複雜且容易維護的網站。

---

# JavaScript 的進化：TypeScript

<br>

**TypeScript (TS)** 是微軟開發的開源程式語言，它是 JavaScript 的「超集」。
（簡單來說：你可以在 TS 裡面寫原本的 JS，但它多了一些強大的保護功能）。

### 為什麼需要它？
- **嚴謹的型別檢查**：原本的 JS 很自由，數字可以突然變成字串。TS 強制規定一個變數是什麼型別，寫錯了在「寫程式的當下」編輯器就會亮紅燈報錯，而不是等到網頁上線才壞掉。
- **自動完成更聰明**：編輯器 (VS Code) 能準確知道物件有哪些屬性，自動提示。

> **現在業界的全新專案，幾乎都是預設使用 TypeScript 來開發。**

---

# 常見的前端框架 (Frameworks)

<br>

為了解決程式碼過於雜亂的問題，「元件化 (Component)」的開發框架成為了主流。就像玩樂高一樣，把網頁拆成一個個獨立的積木（導覽列、卡片、按鈕），然後再將它們拼裝起來。

### 三大主流前端框架：
1. **React**：由 Facebook (Meta) 開發。目前市佔率最高、生態系最齊全。
2. **Vue.js**：學習曲線較平緩，深受亞洲市場喜愛。
3. **Angular**：由 Google 維護，適合超大型企業級專案。

*(現在還有基於這些框架衍生的 Next.js、Nuxt.js 等全端框架，成為了業界的最新標準。)*

# AI 世代的網頁開發

<br>

**「既然現在框架這麼難學，我還是不要做網頁好了...」**

不用擔心！因為現在的開發模式已經徹底改變了。
以往工程師需要花費大量時間解決語法錯誤、查尋技術文件。
現在，**AI 成為了我們最強大的寫程式夥伴 (Pair Programmer)**。

- 你不需要從零死背艱澀的語法。
- 你只需要有「**清晰的邏輯**」與「**規劃能力**」，AI 就會幫你把程式碼生出來。

---

# 常用的 AI 輔助開發工具

<br>

### 1. 通用型語言模型
- **ChatGPT / Claude**：你可以貼上程式碼請他們抓 Bug，或是請他們寫一段特定的功能（例如：「幫我用 React 寫一個倒數計時器」）。

### 2. AI 程式碼編輯器
- **Cursor / GitHub Copilot**：內建在你的開發軟體中。你只要打一行註解，它就會自動幫你補完後面的程式碼。目前 Cursor 是最受工程師歡迎的 AI 開發工具。

### 3. 一鍵生成式平台
- **Bolt.new / v0.dev**：只要用自然語言描述，就能直接在瀏覽器裡生成完整的網頁或是獨立的應用程式介面！

# 瀏覽器裡的開發革命：WebContainers

<br>

過去，如果我們要執行 React 等現代框架，必須在電腦上安裝 Node.js、設定環境變數、安裝一堆依賴套件 (NPM packages)，過程非常痛苦。

現在的技術突破 (例如 WebContainers)，讓我們可以**直接在瀏覽器裡面**運行完整的 Node.js 環境！

> 這意味著，我們可以搭配 AI，在一個網頁分頁裡，用講話的就瞬間搭起一個現代化的前端專案，並且直接預覽跟修改，完全不需要在本地電腦安裝任何東西。
