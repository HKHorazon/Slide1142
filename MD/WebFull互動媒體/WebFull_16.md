# 自我檢查清單

<br>

在上台發表前，請務必檢查以下項目：

### 1. 斷點檢查
-   拿出你的手機，打開你的網站。
-   文字有沒有跑版？圖片有沒有變形？按鈕按得到嗎？
-   **Wix**: 檢查 Mobile Editor 的隱藏元件是否正確顯示。
-   **Code**: 檢查 Media Query 是否在不同寬度下都正常。

### 2.連結測試
-   每一個按鈕、每一個選單連結都要點點看。
-   有沒有連到 "404 Not Found"？
-   外部連結 (IG/FB) 是否有設定 `target="_blank"` (新分頁開啟)？

# 常見錯誤

<br>

### 1. 圖片檔案太大
-   網站載入超過 5 秒，使用者就會離開。
-   請使用 JPG/WebP 格式，並壓縮圖片大小 (TinyPNG)。

### 2. 文字難以閱讀
-   背景太花，文字顏色太淡。
-   **解法**：在文字底下加一層半透明的黑色遮罩，或是增加文字陰影。

### 3. "Lorem Ipsum" 忘了改
-   不要出現假文！請填入真正的內容。
-   即使是虛構的店，也要寫得像真的一樣。

# 繳交與發表準備

<br>

### 1. 錄製操作影片 (備案)
-   現場網路可能會掛掉，或是電腦可能會當機。
-   **強烈建議**先錄一段 1~2 分鐘的網站操作影片 (OBS / 螢幕錄影)。
-   如果現場 Demo 失敗，馬上播影片講解。

### 2. 準備講稿
-   你只有 **5 分鐘**。
-   不要照稿唸 PPT。
-   **重點放在**：
    1.  為什麼做這個主題？(動機)
    2.  你覺得最酷的功能是什麼？(亮點)
    3.  過程中遇到什麼困難？如何解決？(反思)
