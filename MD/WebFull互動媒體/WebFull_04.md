# 為什麼需要規劃？

<br>

蓋房子之前要有藍圖，拍電影之前要有劇本。
做網站也是一樣，**直接寫程式通常會帶來災難**。

-   **避免重工**：做了一半才發現邏輯不通，全部重來。
-   **溝通順暢**：跟業主或組員有共同的視覺依據。
-   **釐清需求**：確保做出来的東西是使用者真正需要的。

> **80% 的問題在規劃階段就能被解決。**

---

# 網站規劃流程

<br>

一個完整的規劃流程包含：

1.  **需求分析**：誰要看？看什麼？
2.  **資訊架構**：內容怎麼分類？
3.  **網站地圖 (Sitemap)**：有哪些頁面？
4.  **線框圖 (Wireframe)**：版面怎麼排？
5.  **視覺稿 (Mockup)**：顏色、圖片長怎樣？
6.  **原型 (Prototype)**：點起來的感覺如何？

---

# 需求分析：目標與受眾

<br>

在動手畫圖前，先問自己兩個問題：

### 網站目標
-   這個網站存在的目的是什麼？
-   **商業目標**：增加銷售量？收集 Email？
-   **品牌目標**：建立專業形象？推廣知名度？

### 目標受眾 (Target Audience)
-   誰會來看這個網站？
-   **年齡層**：年輕人喜歡潮流，長輩需要字體大。
-   **使用情境**：用手機通勤看？還是坐在辦公室用電腦看？

---

# 網站的種類 (以用途來分)


<br>

1. **入口網站 (Portal)**：Yahoo, MSN (資訊匯集站)
2. **電子商務 (E-Commerce)**：PChome, 蝦皮 (買賣東西)
3. **企業形象官網 (Corporate)**：台積電, 弘光科大 (介紹公司)
4. **社群網站 (Social Media)**：FB, IG, Dcard (人際互動)
5. **影音串流 (Streaming)**：YouTube, Netflix (看影片)
6. **個人作品集/部落格 (Portfolio/Blog)**：展示個人專業 (`.md` 轉網站)

# 靜態網頁 vs 動態網頁


<style scoped>
table {
    font-size: 34px;
}
</style>

| 特性 | 靜態網頁 (Static) | 動態網頁 (Dynamic) |
| :--- | :--- | :--- |
| **內容** | 固定不變，所有人看到都一樣 | 根據使用者不同而改變 (個人化) |
| **更新** | 需手動修改 HTML 檔案 | 透過後台系統 (CMS) 修改資料庫 |
| **技術** | HTML + CSS (+ 少許 JS) | HTML/CSS/JS + 資料庫 + 後端語言 |
| **例子** | 個人履歷、形象頁面 | FB 動態牆、購物車、會員系統 |
| **成本** | 低、速度快 | 高、開發複雜 |

# 靜態形象網站規劃 (案例分析)

當我們想要製作一個**介紹性質**的網站（例如：推廣一部喜歡的動漫、遊戲、電影、介紹自己的社團、或是個人作品集），通常屬於**靜態網站**。

這類網站的重點在於：
1. **視覺吸引力**：讓訪客第一眼就覺得「哇！好看！」。
2. **資訊清晰**：讓訪客能快速找到想看的內容。
3. **導覽流暢**：頁面跳轉順暢，不會迷路。

我們以**「動漫介紹網站」**為例，來練習網站規劃。

# 1. 目標與受眾 (Goal & Audience)

### 網站主題：《【推しの子】》互動官網
https://ichigoproduction.com/

- **目標 (Goal)**：
  - 推廣動畫與角色 IP，增加粉絲黏著度。
  - **虛擬與現實交錯**：不僅是動畫官網，更是劇中「莓傳媒 (Ichigo Production)」的官方網站。
  - 整合最新消息、影音、周邊商品資訊。

- **目標受眾 (Audience)**：
  - 原作漫畫粉絲。
  - 喜歡日本偶像/演藝圈文化的年輕族群。


---

# 2. 視覺與風格設定 (Visual Design)

風格是網站的靈魂！在開始寫程式之前，我們先決定「長什麼樣子」。


### 本範例配色：
- **主色調**：
  - **螢光粉紅** `#FF0099`：象徵愛的瞳孔與偶像光環。
  - **星夜黑** `#1a1a1a`：深沉背景，突顯亮色文字。
- **字體**：標題使用極粗黑體 (Gothic)，數字使用斜體 (Italic) 帶出速度感。
- **特效**：星星閃爍 (Sparkle)、雜訊 (Glitch) 暗示劇情的雙面性。

### 關鍵：色碼 (Color Code)
電腦看不懂「粉紅色」或「深藍色」，它只看得懂精準的 **16進位碼 (Hex Code)**。
- **準確性**：`#FF0099` 在全世界任何電腦上看起來都是一樣的粉紅。
- **配色工具推薦**：Coolors.co, Adobe Color。

---

# 3. 首頁與導覽 (Homepage & Navigation)

### 首頁的衝擊感 (Impact)
訪客進入網站的前 3 秒決定了他的去留。
- **Hero Section (主視覺區)**：
  - 使用滿版大圖或影片，佔據第一螢幕。
  - **目的**：瞬間抓住眼球，傳達偶像的閃耀與神秘感。

### 導覽列 (Navbar)
- 就像百貨公司的路標，要清楚、好找，通常位於頁面最上方。
- **設計重點**：
  - 項目不宜過多 (5-7 個以內)。
  - 與背景要有足夠對比度。

---

# 4. 分頁規劃 (Sitemap)

不需要把網站做得像迷宮，先挑選最核心的 4-5 個分頁即可。

### 核心頁面選擇 (參考 Ichigo Production)：
1. **NEWS (最新消息)**：動畫開播、活動公告 (通常要在首頁最顯眼處)。
2. **MOVIE (影片專區)**：預告片 (Trailer)、OP/ED 宣傳 PV。
3. **STREAMING (串流平台)**：Netflix、巴哈姆特動畫瘋連結。
4. **TALENT (藝人介紹)**：以經紀公司角度介紹旗下藝人 (星野愛、B小町)。
5. **BOOKS (原作情報)**：原作漫畫、小說出版資訊。

> **保持簡單**：讓使用者能直覺地找到他們要的資訊，不要讓他們迷路。

這不是真的網頁，只是「圖片」或「設計稿」，讓我們確認排版是否好看。

  - https://www.figma.com/

  - https://www.canva.com/

**目標**：先確認圖片、文字的位置與大小，**先設計再寫 Code，才不會一直改來改去。**

# 網站內容準備

<br>

在此階段，除了畫圖，也要開始準備網站要放的「素材」。

### 文字
-   **標題**：要吸引人 (Copywriting)。
-   **內文**：要簡潔易讀，分段落。
-   **CTA (Call to Action)**：引導使用者點擊的文字 (例如：「立即註冊」、「了解更多」)。

### 圖片
-   **照片**：產品照、情境照。
-   **圖標**：功能示意的圖示 (如 🔍 代表搜尋)。
-   **插畫**：增加親和力與風格。

# 圖片版權

<br>

這是最重要的一點！**網路上的圖片不能隨便抓來用！**

### 創用 CC
-   **CC0 (公眾領域)**：這才是你可以隨便用的。不用標示出處，可以商用，可以改作。

### 推薦 CC0 圖庫：
1.  **Unsplash**：高品質攝影照片，風格文青。
2.  **Pexels**：照片與短影片都有。
3.  **Pixabay**：量大，包含插畫與向量圖。

> 養成好習慣，盡量使用圖庫或自己拍攝/繪製的素材。

# 圖片格式選擇

<br>

網頁用的圖片格式很有講究：

| 格式 | 特性 | 適用時機 |
| :--- | :--- | :--- |
| **JPG / JPEG** | 破壞性壓縮，檔案小，不支援透明 | 照片、色彩豐富的圖 |
| **PNG** | 無損壓縮，檔案大，支援背景透明 | Logo、去背圖、截圖 |
| **SVG** | 向量圖，放大不失真，程式碼可控 | Icon、Logo、簡單幾何圖 |
| **GIF** | 支援動畫，色彩少 (256色) | 迷因圖、簡單動畫 |
| **WebP** | Google 推出的新格式，兼具高品質與小檔案 | 現代網頁通用 (推薦) |

# 配色心理學

<br>

顏色會影響人的情緒與感受。

-   **紅色**：熱情、警告、特價 (可口可樂, Netflix)。
-   **藍色**：專業、冷靜、信任 (FB, Twitter, 銀行)。
-   **綠色**：自然、健康、金錢 (Line, 星巴克, Spotify)。
-   **黑色**：高級、時尚、神祕 (Apple, Chanel)。
-   **黃色**：快樂、警示、活力 (McDonald's, SnapChat)。

> 選擇配色時，要符合你的網站主題與 TA 喜好。

---

# 配色規則

<br>

不要亂配顏色，遵循色彩學規則：

-   **單色系**：同一個顏色，調整深淺。最安全。
-   **互補色**：色環上相對的顏色 (紅配綠、藍配橘)。對比強烈，適合突顯重點。
-   **相似色**：色環上相鄰的顏色 (藍配綠、紅配橘)。視覺協調舒服。

> **推薦工具**：Coolors.co, Adobe Color 可以幫你自動生成配色。

---

# 字體排版

<br>

網頁 90% 的內容是文字，排版好不好看決定了一切。

### 字體選擇
-   **黑體**：無襯線，現代、簡潔 (Roboto, Noto Sans)。螢幕閱讀首選。
-   **明體**：有襯線，古典、文學 (Times New Roman, 思源宋體)。適合長篇文章。

### 排版原則
-   **層級**：標題要大且粗，內文要小且細。
-   **行距**：不要擠在一起，通常設定 1.5 倍行距最舒服。
-   **字重**：善用粗細變化來強調重點。

---

# 網頁佈局趨勢：Hero Section

<br>

**Hero Section** 是首頁最上方的區塊，決定第一印象。

### 常見設計：
-   **滿版大圖**：一張震撼的照片 + 標題。
-   **文字為主**：超大標題 (Typography) + 簡單插畫。
-   **影片背景**：自動播放的情境影片。
-   **分割畫面**：左文右圖，清楚直觀。

要包含明確的 **CTA (Call To Action)** 按鈕，告訴使用者下一步該做什麼。

---

# 情緒版 (Mood Board) - 設計師的祕密武器

<br>

在開始畫 Mockup 之前，先做一個 **Mood Board**。

-   **收集靈感**：把你覺得「這個感覺對了」的圖片、配色、字體、材質全貼在一個版面上。
-   **定調風格**：看著這一堆圖片，你會對網站的氛圍更有把握。
-   **溝通工具**：跟業主或組員確認「是不是這種感覺？」，避免雞同鴨講。

> Pinterest 是尋找 Mood Board 靈感的最佳網站。

---

# 響應式網頁設計規劃

<br>

規劃時不能只畫電腦版！

-   **行動優先 (Mobile First)**：先思考手機版怎麼呈現，因為空間最小，必須去蕪存菁，留下最重要的內容。
-   **斷點**：思考在不同螢幕寬度下，版面要怎麼變化？
    -   原本三欄的卡片，在平板變兩欄，在手機變一欄。
    -   原本橫向的導覽列，在手機變成漢堡選單。
