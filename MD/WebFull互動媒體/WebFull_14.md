# 什麼是 Bolt.new？

<br>

[**Bolt.new (https://bolt.new/) **](https://bolt.new/) 是一個由 StackBlitz 團隊開發的「**AI 驅動全端 Web 開發環境**」。

簡單來說：
你只要在瀏覽器中打字跟 AI 聊天，告訴它你想做什麼網站，
它就會**自動幫你在瀏覽器裡面建立專案、寫程式碼、安裝套件、並跑出一個即時的網頁畫面給你看**！

> **你不需要安裝任何軟體，一切都在瀏覽器中發生。**

---

# 為什麼 Bolt.new 這麼強？

<br>

### 1. 突破傳統框架門檻
如果是以前，你要寫一個 React + Tailwind CSS 的網站，光是前期安裝環境就可以搞掉一整堂課。在 Bolt，你只要輸入「給我一個 React 基礎專案」，幾秒鐘內一切就緒。

### 2. 不是只能生成單一檔案
ChatGPT 或一般 AI 工具通常只能給你「一段獨立的程式碼」。
但 Bolt 給你的是「**一整個可以運作的系統**」。它背後能夠運行真正的終端機 (Terminal) 和虛擬環境，有完整的資料夾結構。

---

# 介面介紹

<br>

打開 Bolt.new 後，它的介面非常直覺，主要分為三大區塊：

1. **左側 (對話聊天室)**：這是你跟 AI 溝通的地方。提出需求、回報錯誤，都在這裡發送訊息。
2. **右側 (即時預覽視窗)**：你的網站的渲染畫面。你可以直接在上面點擊操作，測試互動性。
3. **右側切換 (資料夾結構、終端機、預覽視窗)**：AI 幫你寫的多個原始碼檔案。如果你懂程式碼，可以直接在這邊手動修改，網頁就會立刻熱更新！

> 就像是你有一個資深工程師 (AI) 坐在你旁邊，你說一句，他幫你寫一行。

# Prompt (提示詞) 撰寫訣竅

<br>

要讓 AI 產出好東西，你必須學會怎麼精準地「下指令」。

- **❌ 壞指令**：「做一個賣衣服的網站。」(太模糊，AI 會隨便猜你要什麼)
- **✅ 好指令**：「做一個**極簡風格**的女裝購物網站首頁。要有**包含三個項目的導覽列**。中間要有**一張全版的大圖 (Hero section)**，並有一個**加入購物車的按鈕**。配色以黑白灰為主。」

**口訣：情境 + 結構 + 風格 + 功能**

# 替換圖片

<br>

AI 預設生成的網站，通常會使用 Unsplash 的隨機圖片。
如果你想換成「自己設計」或「先千用 AI 生成」的圖片，有幾種做法：

1. **上傳圖片 (最直接)**：
   - 點擊右下角原始碼區塊，找到 `public` 或 `assets` 資料夾。
   - 直接把你的圖片直接拖曳進去。
   - 告訴 AI：「幫我把首頁的大圖換成剛上傳的 `hero-bg.jpg`」。

2. **使用圖片網址**：
   - 先把你的圖片上傳到圖床 (如 Imgur)。
   - 將圖片的直連網址貼給 AI：「把這個區塊的圖片換成 `https://.../img.jpg`」。

# 漸進式修改 (Iterative Refinement)

<br>

不要預期 AI 可以一次就把完美的網站變出來。
正確的使用方式是「**一步一步來**」。

1. 先請它建出大概的框架 (例如首頁的區塊配置)。
2. 然後要求修改細節：「把導覽列的字體變大」、「按鈕顏色換成橘色」。
3. 接著加入新頁面或功能：「再幫我加一個『關於我們』的頁面」或「幫我加上計時功能」。
4. 遇到跑版或錯誤：「剛剛講的那個按鈕在手機版看起來跑版了，幫我修好」。

把 AI 當作是人類同事一樣不斷來回溝通！

# 免費版限制與使用策略

<br>

Bolt.new 雖然強大，但免費帳號在體驗時有一些會遇到的限制：

1. **Token 限制 (對話額度)**：對話如果太長或生成太多程式碼，免費的 AI 額度會耗盡（會跳出提醒）。這時候需要等待一段時間（每天重置）才能繼續。
2. **適時開啟新對話 (New Chat)**：如果目前的網站功能已經很龐大，AI 回覆會變慢且容易出錯。
3. **專案公開**：免費版生成的專案預設都是公開的，任何人有網址都能看到。

# 下載與發布網站

<br>

既然都在雲端生成了，該怎麼把網站保存下來或讓別人看到？

1. **Download 原始碼 (推薦)**：點擊右上角的下載按鈕，把整個專案打包成 ZIP 下載到你的電腦裡。解壓縮後就是標準的程式碼專案，你可以用熟悉的 VS Code 打開它。
2. **Deploy (一鍵上線)**：Bolt 左邊欄的「Deploy」按鈕，可以無縫整合 Netlify 雲端伺服器服務。按下去，幾分鐘後就能產生一個公開的網址，直接傳給朋友炫耀！
