### Chapter 02
# 網站類型介紹

## WebFull 互動媒體 (一學期)

---

# 為什麼要了解網站類型？

<br>

在開始製作網站之前，我們必須先了解**目標是什麼**。
不同的網站有不同的目的、不同的受眾，以及不同的功能需求。

了解常見的網站類型，可以幫助我們：
1. **確認需求**：知道自己需要哪些功能。
2. **參考範例**：找尋相同類型的網站作為設計靈感。
3. **選擇技術**：決定要用簡單的靜態網頁，還是複雜的動態系統。

---

# 1. 企業形象網站 (Corporate)

<br>

- **目的**：展示公司品牌形象、介紹服務與產品、提供聯絡資訊。
- **特點**：重視視覺設計、質感，內容更新頻率較低。
- **範例網址**：
  - Apple 台灣 (https://www.apple.com/tw/)
  - 星巴克台灣 (https://www.starbucks.com.tw/)

---

# 2. 電子商務網站 (E-Commerce)

<br>

- **目的**：在網路上銷售實體或虛擬商品。
- **特點**：需要購物車、會員系統、金流（付款）與物流設定。安全性要求極高。
- **範例網址**：
  - 蝦皮購物 (https://shopee.tw/)
  - momo 購物網 (https://www.momoshop.com.tw/)

---

# 3. 新聞與資訊網站 (Portal)

<br>

- **目的**：提供大量的新聞、文章、生活資訊。
- **特點**：資料量龐大、更新速度極快、需要良好的分類與搜尋功能。
- **範例網址**：
  - Yahoo 奇摩 (https://tw.yahoo.com/)
  - 巴哈姆特電玩資訊站 (https://www.gamer.com.tw/)

---

# 4. 部落格 / 雜誌 (Blog / Magazine)

<br>

- **目的**：個人或團隊分享文章、心得、教學、故事。
- **特點**：以文字與圖片為主，常有文章分類與留言功能。
- **範例網址**：
  - Medium (https://medium.com/)
  - 痞客邦 (https://www.pixnet.net/)

---

# 5. 社群平台 (Social Media)

<br>

- **目的**：讓使用者建立個人檔案、分享內容、互相交流與追蹤。
- **特點**：高度互動性，內容全部由使用者產生 (UGC)。需要強大的伺服器支援。
- **範例網址**：
  - Instagram (https://www.instagram.com/)
  - Facebook (https://www.facebook.com/)


---

# 什麼是靜態網頁與動態網頁？

<br>

我們可以把網頁簡單分成這兩種運作方式：

- **靜態網頁 (Static)**：就像一本**印好的實體書**。
- **動態網頁 (Dynamic)**：就像餐廳**現點現出**。

---

# 什麼是靜態網頁 (Static Web Page)？

<br>

**「靜態」不是指畫面不會動**，而是指「內容是固定的」。

- **運作方式**：網頁檔案寫好放在伺服器上，任何人來連線，看到的內容都 **一模一樣**。
- **就像是一本實體書**：印好之後，不管是誰打開來看，裡面的文字和圖片都不會變。
- **優點**：載入速度很快、製作成本較低、非常安全（因為沒有資料庫可以被駭）。
- **缺點**：如果想要修改內容（例如換一張圖片、改一段文字），必須由工程師直接修改程式碼。

---

# 什麼是動態網頁 (Dynamic Web Page)？

<br>

**「動態」是指內容會因為不同人、不同時間而改變。**

- **運作方式**：伺服器會即時查資料庫（Database），把資料「組裝」成網頁再傳送出來。
- **就像是餐廳點餐**：你點了什麼，廚房（伺服器）就馬上做出一份專屬你的餐點。
- **優點**：內容容易更新（可以有後台管理系統）、能做到登入、購物車等個人化功能。
- **缺點**：開發成本高、載入速度相對較慢、需要維護伺服器的安全。
- **例子**：你的 Facebook 首頁跟別人的不一樣，這就是最標準的動態網頁。

---

# 需要的技術大不同！

<br>

### 靜態網頁需要的技術（前端基礎）：
*只要有這些，就能做出漂亮的畫面！*
1. **HTML**：負責網頁的**結構**（文字、標題、圖片）。
2. **CSS**：負責網頁的**外觀排版**（顏色、大小、位置）。
3. **JavaScript (基礎)**：負責網頁的**簡單互動**（如：點按鈕會跳出選單、圖片輪播）。

---

# 需要的技術大不同！(續)

<br>

### 動態網頁需要的額外技術（後端與資料庫）：
*除了前面的基礎，還需要加上這個「大腦與記憶」！*
1. **後端程式語言**：如 PHP, Python, Java, Node.js 等。負責思考邏輯，例如「這個帳號密碼對不對」。
2. **資料庫 (Database)**：如 MySQL, MongoDB。用來記憶所有的會員資料、商品圖文、留言內容。
3. **伺服器架設**：需要更進階的電腦環境來執行這些後端程式與儲存檔案。

| 比較項目 | 靜態網頁 (Static) | 動態網頁 (Dynamic) |
| :--- | :--- | :--- |
| **內容呈現** | 所有人看都一樣 | 依使用者或時間變化 |
| **開發難易度** | 簡單 (適合初學者) | 困難 (需要前後端技術) |
| **載入速度** | 較快 | 較慢 (需要運算時間) |
| **內容更新** | 需工程師改程式碼 | 可透過後台系統更新 |
| **適用網站** | 形象官網、活動宣傳頁 | 購物商城、社群網站、論壇 |
| **核心技術** | HTML, CSS, JavaScript | HTML, CSS, JS + 後端 + 資料庫 |

# 網頁設計的常見職位

<br>

一個完整的網站開發需要不同專業的合作：

1. **設計師 (UI/UX Designer)**：負責網站的**視覺規劃與使用體驗** (畫圖、配色)。
2. **前端工程師 (Front-End)**：負責**看得到的部分**。技術：HTML/CSS/JS。
   - 🔹 *趨勢：許多職缺要求「設計 + 前端」一人包辦。*
3. **後端工程師 (Back-End)**：負責**看不到的邏輯** (驗證、資料庫)。技術：PHP/Python等。
4. **全端工程師 (Full-Stack)**：**包山包海**，同時精通「前端 + 後端」的開發者！
